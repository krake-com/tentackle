# Tentackle TRIP over Cloudflare quiche

A pluggable QUIC (RFC-9000) transport for TRIP, built on Cloudflare's quiche through the Java FFM API.
The sibling of [tentackle-quic](../tentackle-quic/), which provides the same transport on the pure-Java
KWIK stack; the two register different URI schemes and interoperate.
