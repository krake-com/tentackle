# Tentackle Keyring

Opt-in backends for the keyring API of tentackle-core: the macOS keychain, the Windows Credential Manager and
the freedesktop.org Secret Service, bound directly through the Java FFM API, without any third-party runtime
dependency. Adding the module to an application replaces the default keyring, which keeps secrets such as
single sign-on tokens in the Java preferences.
